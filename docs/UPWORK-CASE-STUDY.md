**Title:** Business Automation Platform | CRM Dashboard & Real Workflow Engine

**Role:** Full-stack Developer & UI/UX Designer — Independent Demonstration

**Description:**

Northstar Ops is an independent full-stack portfolio project built to demonstrate how a service business can manage leads, customers, projects and everyday workflows in one clean interface.

I designed the responsive dashboard, built persistent CRUD operations with Node.js and SQLite, and implemented four server-side workflows: inquiry capture, lead follow-up, customer conversion and automatic project completion. Workflows include execution records, on/off controls and duplicate-prevention logic. Each demo visitor gets an isolated workspace filled with fictional sample data.

Key functionality includes interactive pipeline management, connected customer and project records, task progress, live record-based charts, searchable tables, in-app notifications, activity history, light/dark themes and mobile layouts.

**Verification:** Eight backend test suites passed. Desktop, tablet and mobile layouts were reviewed. Browser-driven tests confirmed that an inquiry creates a stored lead and an execution record, and that manual follow-up execution is logged. This is a fictional product demonstration, not a commissioned client project.

**Technologies:** JavaScript, HTML, CSS, Node.js, SQLite, SVG, Node.js Test Runner.
